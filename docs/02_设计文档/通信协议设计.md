# MyQQ 通信协议设计

## 1. 传输层
- 协议：**TCP**（Winsock 2），阻塞式，局域网内通信。
- 端口：默认 `6000`（`myqq::kDefaultPort`）。
- 连接方式：客户端输入服务端的**局域网 IPv4**（如 `192.168.x.x`）+ 端口连接。
- 编码：UTF-8 文本。

## 2. 报文格式
一条报文一行，以 `\n` 结束。字段以 `|` 分隔：
```
CMD|arg1|arg2|...\n
```
- 首字段为命令名。
- 由 `src/common/Message.cpp` 的 `Pack` / `Unpack` 负责序列化与解析。
- 服务端做了粘包/半包处理（`TcpSocket::RecvLine` 按 `\n` 切分缓冲）。

## 3. 命令一览

### 3.1 请求（客户端 → 服务端）

| 命令 | 格式 | 说明 |
|------|------|------|
| REGISTER | `REGISTER\|account\|password\|nickname` | 注册 |
| LOGIN | `LOGIN\|account\|password` | 登录，成功后服务端登记在线 |
| SEARCH | `SEARCH\|keyword` | 按账号/昵称模糊查找（排除自己） |
| ADD_FRIEND | `ADD_FRIEND\|fromId\|toId\|verify` | 双向加好友 |
| FRIEND_LIST | `FRIEND_LIST\|userId` | 获取好友列表 |
| CHAT | `CHAT\|fromId\|toId\|content` | 发送聊天消息 |
| VERSION | `VERSION` | 查询软件版本 |
| PING | `PING` | 心跳 |

### 3.2 响应（服务端 → 客户端）

| 响应 | 格式 | 说明 |
|------|------|------|
| REGISTER_RESP | `REGISTER_RESP\|status\|payload` | status=0 成功(payload=新userId)，4 账号已存在 |
| LOGIN_RESP | `LOGIN_RESP\|status\|payload` | status=0 成功(payload=userId)，2 账号或密码错误 |
| SEARCH_RESP | `SEARCH_RESP\|status\|count\|[id,account,nick,status]*` | 命中列表 |
| ADD_FRIEND_RESP | `ADD_FRIEND_RESP\|status` | 0 成功 |
| FRIEND_LIST_RESP | `FRIEND_LIST_RESP\|status\|count\|[id,account,nick,status]*` | 好友列表 |
| CHAT_ACK | `CHAT_ACK\|status` | 服务端已收下并入库 |
| VERSION_RESP | `VERSION_RESP\|version` | 版本号 |
| PONG | `PONG` | 心跳回应 |

### 3.3 服务端主动推送

| 推送 | 格式 | 触发 |
|------|------|------|
| CHAT_PUSH | `CHAT_PUSH\|fromId\|content` | 有人给在线用户发消息时实时下发 |
| SYS_MSG | `SYS_MSG\|content` | 系统通知（如被添加为好友） |

## 4. 状态码（`myqq::Status`）
| 值 | 含义 |
|----|------|
| 0 | 成功 |
| 1 | 参数错误/失败 |
| 2 | 认证失败 |
| 3 | 未找到 |
| 4 | 已存在 |
| 5 | 服务器错误 |

## 5. 典型交互时序

### 登录并接收消息
```
Client(bob)                     Server                    Client(alice)
   | LOGIN|bob|456                 |                            |
   |----------------------------->| 校验DB, 登记在线            |
   |<-----------------------------| LOGIN_RESP|0|10002          |
   |                              |         LOGIN|alice|123     |
   |                              |<----------------------------|
   |                              |         CHAT|10001|10002|hi |
   |                              |<----------------------------|
   |                              | 存Messages表                |
   |<-----------------------------| CHAT_PUSH|10001|hi          |
   |  (接收线程显示消息)           |---------------------------->| CHAT_ACK|0
```

## 6. 客户端实现要点
- 单独的**接收线程**持续 `RecvLine`，收到 `CHAT_PUSH`/`SYS_MSG` 时刷新 UI（MFC 用 `PostMessage` 回主窗口）。
- 聊天消息本地同时写入 `ChatLogger`（满足"自动建立文件存储聊天记录"）。
- 已在 `src/client/ConsoleClient.cpp` 用接收线程验证过推送链路。
