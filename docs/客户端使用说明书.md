# MyQQ 客户端使用说明书

本说明书面向**使用客户端聊天的用户**。教你从打开软件到和好友聊天的每一步操作。

---

## 一、开始之前

在使用客户端前，请确认：

1. **服务端已经启动**。MyQQ 是联网软件，必须有一台机器在运行服务端 `MyQQServer.exe`，你才能连上去。
2. **你知道服务端的 IP 和端口**。向运行服务端的同学要：
   - 服务器 IP（形如 `192.168.1.20`；如果服务端就在你这台机器上，用 `127.0.0.1`）
   - 端口（默认 `6000`）
3. **你和服务端在同一个局域网**（同一路由器 / 同一 WiFi）。本软件只支持局域网通信。

---

## 二、软件界面总览

客户端共有 5 个窗口，按使用顺序：

1. **登录窗口** —— 打开软件先看到它，用来连接服务器、登录、进入注册。
2. **注册窗口** —— 没有账号时先注册。
3. **主窗口** —— 登录后进入，显示好友列表，查找 / 添加好友，进入聊天、打开个人设置。
4. **聊天窗口** —— 和某个好友一对一聊天，可以同时开多个。
5. **个人设置窗口** —— 编辑自己的昵称、性别、星座、血型、头像、签名。

---

## 三、第一步：注册账号

第一次使用需要先注册。

1. 双击 `MyQQClient.exe` 打开软件，进入**登录窗口**。
2. 先填好上方的**服务器 IP** 和**端口**（比如 `192.168.1.20` / `6000`）。
3. 点「**注册**」按钮，弹出**注册窗口**。
4. 填写：
   - **账号**：你自己取的**登录名**（不能和别人重复），比如 `alice`。以后就用它登录。
   - **密码** / **确认密码**：两次要一致。点密码框右边的「**显 / 隐**」按钮可切换密码明文/密文显示。
   - **昵称**：好友看到的**显示名**，可以是中文，可以和账号不一样。
5. 点「**提交注册**」。
6. 看到「注册成功」提示，会告诉你系统分配的 **QQ 号**（如 `10001`）。

> **账号 vs QQ 号**：**账号**是你自己取的登录名，登录时用「账号 + 密码」；**QQ 号**是系统自动分配的身份编号，加好友、聊天时在内部标识你。两者不是一回事 —— 登录请用账号，不是那串数字。
>
> 如果提示「账号已存在」，换一个账号名再试。

---

## 四、第二步：登录

1. 在**登录窗口**填写：
   - **账号**、**密码**：刚才注册的（注意用**账号**登录，不是 QQ 号）。密码框右边有「**显 / 隐**」按钮可切换密码是否可见。
   - **服务器 IP**、**端口**：确认填对
2. （可选）点「**查询本机**」，会显示你这台机器的主机名和 IP —— 这只是方便你查看本机网络信息，不影响登录。
3. 点「**登录**」。
4. 登录成功后，登录窗口关闭，进入**主窗口**。

> 如果提示「账号或密码错误」，检查账号密码；如果提示「连接服务端失败」，检查服务器 IP / 端口是否正确、服务端是否在运行（见文末排查表）。

---

## 五、第三步：添加好友

登录后在**主窗口**操作：

1. 在上方**查找框**输入对方的账号或昵称关键字。
2. 点「**查找/添加**」按钮。
3. 找到用户后，会弹窗显示结果并询问「是否添加为好友」，点「**是**」。
4. 添加成功后，点「**刷新**」按钮，好友列表里就会出现这位好友。

好友列表每一行显示：**ID、昵称、在线状态**（在线 / 离线）。

---

## 六、第四步：和好友聊天

1. 在**主窗口**的好友列表里**选中**一位好友。
2. 点「**打开聊天**」按钮，或者**双击**该好友，打开**聊天窗口**。
3. 在下方输入框打字，点「**发送**」（或按发送按钮）把消息发出去。
4. 你的消息会显示在上方对话区，格式为 `[时间] 我: 内容`。
5. 对方**在线时**，你的消息会**实时送达**；对方回复也会实时出现在你的聊天窗口里，格式为 `[时间] 对方昵称: 内容`。

**可以同时和多个好友聊天** —— 每位好友一个独立的聊天窗口。

> 聊天记录会**自动保存到文件**：软件目录下的 `logs/` 文件夹里，每个会话一个文本文件（按双方 ID 命名）。即使关掉软件，记录也还在。

---

## 七、第五步：编辑个人资料

登录后在**主窗口**点「**个人设置**」按钮，打开**个人设置窗口**：

1. 窗口打开时会**自动读取**你当前的资料并填好各栏。
2. 可修改：**昵称、性别、星座、血型、头像、个性签名**（账号只读，不可改）。
3. 改完点「**保存**」；不想改就点「**取消**」直接关闭。
4. 保存成功后，主窗口标题里的昵称会同步更新。

> 说明：不修改任何一栏也可以直接保存，原值会原样保留。窗口刚打开、资料还没加载完时点保存，会提示「稍候再保存」，等一下即可。

---

## 八、其他功能

### 查询软件版本
在**登录窗口**或**聊天窗口**里**右键单击窗口**，弹出菜单，点「查询软件版本」，会显示当前版本号。

### 退出
- 关闭主窗口即退出登录（会通知服务端你已离线）。
- 关闭聊天窗口只是关掉那个会话，不影响登录状态。

## 九、完整操作流程速查

```
打开客户端
   ↓
登录窗口：填服务器 IP + 端口
   ↓
没账号？→ 点「注册」→ 填账号/密码/昵称 → 提交 → 记住 QQ 号 → 返回
   ↓
填账号密码 → 点「登录」
   ↓
主窗口：查找框输入对方账号 → 「查找/添加」→ 选「是」→ 「刷新」
   ↓
选中好友 → 「打开聊天」→ 输入消息 → 「发送」
   ↓
对方在线即实时收发；记录自动存到 logs/
   ↓
（可选）主窗口「个人设置」→ 改昵称/性别/星座/血型/头像/签名 → 保存
```

## 十、常见问题

| 现象 | 怎么办 |
|------|--------|
| 「连接服务端失败」 | 确认服务端在运行；服务器 IP / 端口填对；和服务端在同一局域网；服务端防火墙放行了端口 |
| 「账号或密码错误」 | 检查账号密码；确认已经注册过。登录用**账号**不是 QQ 号 |
| 「账号已存在」 | 注册时换一个账号名 |
| 分不清账号和 QQ 号 | **账号**是你自己取的登录名；**QQ 号**是系统分配的编号。登录用账号，加好友用 QQ 号 |
| 好友列表看不到刚加的人 | 点「刷新」按钮 |
| 消息发了对方没收到 | 对方需要**在线**才能实时收到；对方离线时消息已存服务器，但不会即时弹出 |
| 个人设置提示「资料尚未加载完成」 | 稍等资料从服务器返回后再点保存（正常一两秒内就绪） |
| 界面中文乱码 | 客户端需用 `/utf-8` 编译（工程已配置好，正常不会出现） |
| 找不到聊天记录 | 在客户端 exe 所在目录的 `logs/` 文件夹里 |

---

## 十一、小提示

- 测试时如果只有一台电脑，可以**多开几个客户端**（多次双击 exe），注册不同账号，自己和自己聊，一样能验证全部功能。
- 服务器 IP 填 `127.0.0.1` 表示「本机」，适合单机测试；连别人的服务端要填对方的**内网 IP**。
